DMALL — External API

Клиенты настраивают и оплачивают рассылку на этом сайте. Ваш сервис забирает оплаченные задания через этот API, сам выполняет рассылку в Discord и отправляет статус обратно. Ниже — всё, что нужно разработчику.

Base URLhttps://api.vemoni.info
API key— (только для владельца)
Авторизация: заголовок Authorization: Bearer <API key> (или X-Api-Key: <key>). Server-to-server, ключ держать в секрете.

Жизненный цикл задания

paid → (вы claim) claimed → (progress) running → (complete) done / failed. Задание оплачено клиентом в момент создания.

Рабочий цикл сервиса

  1. Опрашивайте GET /dmall/v1/jobs?status=paid (например, раз в 10–30 c).
  2. На каждое задание — POST /dmall/v1/jobs/:id/claim (чтобы два воркера не отправили дважды). 409 = уже занято/не в статусе paid.
  3. Рассылайте. Периодически шлите POST /dmall/v1/jobs/:id/progress с sent/failed.
  4. По завершении — POST /dmall/v1/jobs/:id/complete со статусом done или failed.

Endpoints

GET/dmall/v1/pingпроверка ключа/связи → { ok:true }
GET/dmall/v1/jobs?status=paid&limit=100список заданий (по статусу) → { jobs:[…] }
GET/dmall/v1/jobs/:idодно задание → { job }
POST/dmall/v1/jobs/:id/claimтело { worker } → 200 { job } · 409 если не paid
POST/dmall/v1/jobs/:id/progressтело { sent, failed, note, running } → { job }
POST/dmall/v1/jobs/:id/completeтело { status:"done"|"failed", sent, failed, note } → { job }

Пример

# забрать оплаченные задания
curl -H "Authorization: Bearer $KEY" \
     "https://api.vemoni.info/dmall/v1/jobs?status=paid"

# занять задание
curl -X POST -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
     -d '{"worker":"node-1"}' \
     "https://api.vemoni.info/dmall/v1/jobs/dm_lz9.../claim"

# прогресс и завершение
curl -X POST -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
     -d '{"sent":1200,"failed":15}' ".../dmall/v1/jobs/dm_lz9.../progress"
curl -X POST -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
     -d '{"status":"done","sent":4980,"failed":20}' ".../dmall/v1/jobs/dm_lz9.../complete"

Ошибки: 401 неверный ключ · 404 нет задания/маршрута · 409 конфликт статуса · 503 API не сконфигурирован (не задан DMALL_API_KEY).
